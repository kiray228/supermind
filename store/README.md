Тексты и ответы для анкет лежат в соседних файлах. Здесь — порядок действий.
- [google-play.md](google-play.md) — описание, Data safety, декларации
- [app-store.md](app-store.md) — описание, ключевые слова, «этикетки» конфиденциальности, заметки для проверяющих

## Что уже готово в коде (ветка `store-release`)

| | Google Play | App Store |

| Сборка | `npm run aab` → AAB, подпись текущим ключом | iOS-проект `ios/`, сборка на облачном Mac: `.github/workflows/ios.yml` |
| Разрешения | убран `USE_EXACT_ALARM` (Play даёт его только будильникам). Точные будильники пользователь включает сам: приложение попросит при включении «Как будильник» | Info.plist: объяснения для микрофона, распознавания речи и «Фото»; `PrivacyInfo.xcprivacy` |
| Политика конфиденциальности, удаление аккаунта, поддержка | `public/privacy.html`, `delete-account.html`, `support.html` → GitHub Pages | те же |

| Вход | обязателен, как и раньше | «Продолжить без аккаунта» (правило 5.1.1) |
| Только Android | виджеты, будильник со звонком, календарь телефона, «Прятать в недавних» | на iPhone скрыты: напоминания приходят уведомлениями, задачи выгружаются в Календарь файлом .ics |

## Что нужно сделать перед подачей (один раз)

1. **Email поддержки** — jarvis.soft.kz@gmail.com (уже на страницах сайта). Его же укажите как контактный email разработчика в обеих консолях.
2. **Слить ветку `store-release` в main.** После этого страницы появятся на https://kiray228.github.io/supermind/privacy.html (и delete-account.html, support.html). Магазины проверяют, что ссылки открываются.
3. **Демо-аккаунт для проверяющих.** Зарегистрируйте в приложении отдельный аккаунт (например, review.supermind@…) и добавьте в него пару карт и задач. Логин и пароль впишете в обе консоли.

## Google Play

Стоимость: **$25 один раз**.

1. **Аккаунт разработчика.** https://play.google.com/console/signup → «Для себя» (личный аккаунт). Нужны: Google-аккаунт, оплата картой, проверка личности (паспорт/удостоверение), подтверждение телефона и проверка на Android-устройстве через приложение Play Console. Проверка занимает от нескольких дней до 1–2 недель.
2. **Создать приложение.** «Создать приложение» → название «SuperMind: карты и задачи», язык по умолчанию — русский, «Приложение», «Бесплатно».
3. **Подпись — решить ДО первой загрузки, потом не поменять.** Чтобы тем, кто уже поставил APK с GitHub, приходили обновления из Play, Google должен подписывать приложение нашим текущим ключом:
   «Тестирование и выпуск» → «Целостность приложения» → «Подпись приложения» → «Использовать существующий ключ» → «Экспортировать и загрузить ключ из хранилища Java». Скачайте `pepk.jar` и ключ шифрования. Затем выполните (пароли — из `android/keystore.properties`):
   ```
   java -jar pepk.jar --keystore=android/2mind-release.jks --alias=2mind --output=supermind-signing-key.zip --include-cert --rsa-aes-encryption --encryption-key-path=encryption_public_key.pem
   ```
   Загрузите `supermind-signing-key.zip`. Ключ загрузки — тот же `2mind-release.jks`. Могу сделать эту команду за вас, когда скачаете файлы.
4. **Сборка AAB.** Попросите меня «собрать AAB для Play»: та же схема, что и для APK (чистая копия в C:/dev/tmp, JDK 21), только `bundleRelease`. Файл: `android/app/build/outputs/bundle/release/app-release.aab`. Номер версии (`versionCode`) должен быть больше, чем у любого загруженного ранее.
5. **Закрытое тестирование — обязательно для новых личных аккаунтов.** Перед выпуском для всех Google требует **12 тестировщиков, которые 14 дней подряд держат приложение установленным**.
   «Тестирование» → «Закрытое тестирование» → создать трек → загрузить AAB → добавить email-адреса Google-аккаунтов 12+ человек → разослать им ссылку на участие. Через 14 дней — «Запросить доступ к рабочей версии» (короткая анкета о тестировании).
6. **Страница и анкеты.** Всё из [google-play.md](google-play.md): описание, графика, «Контент приложения», Data safety, декларации сервиса переднего плана (нужно короткое видео с будильником) и полноэкранных уведомлений.
7. **Выпуск.** «Рабочая версия» → создать выпуск → тот же AAB → отправить на проверку. Первая проверка: от нескольких часов до 7 дней.

## App Store

Стоимость: **$99 в год**.

1. **Apple Developer Program.** Нужен Apple ID с двухфакторной защитой. Проще всего записаться через приложение **Apple Developer** на iPhone → Account → Enroll (как частное лицо, Individual). Продавцом в App Store будет указано ваше имя. Для названия компании нужен номер D-U-N-S (бесплатно, но дольше). Подтверждение — от 1 до нескольких дней.
2. **Идентификатор приложения.** https://developer.apple.com/account → Certificates, Identifiers & Profiles → Identifiers → «+» → App IDs → App → Explicit Bundle ID: `app.twomind.mindmap`, описание SuperMind. Дополнительные возможности (capabilities) не нужны.
3. **Карточка в App Store Connect.** https://appstoreconnect.apple.com → «Приложения» → «+» → «Новое приложение»: iOS, название «SuperMind: карты и задачи», основной язык — русский, Bundle ID `app.twomind.mindmap`, SKU `supermind`.
4. **Ключ API для облачной сборки.** «Пользователи и доступ» → «Интеграции» → App Store Connect API → «Ключи команды» → «+», роль **Admin** (иначе облачная подпись не создаст сертификат). Скачайте `.p8` — его дают **один раз**. Запишите Key ID и Issuer ID. Team ID — на https://developer.apple.com/account → Membership.
5. **Секреты в GitHub** (Settings → Secrets and variables → Actions, или командой в папке проекта):
   ```
   gh secret set APPLE_TEAM_ID --body "XXXXXXXXXX"
   gh secret set APPLE_API_KEY_ID --body "XXXXXXXXXX"
   gh secret set APPLE_API_ISSUER_ID --body "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
   gh secret set APPLE_API_KEY_P8 < AuthKey_XXXXXXXXXX.p8
   ```
6. **Сборка и загрузка.** GitHub → Actions → «Build iOS app» → Run workflow → галочка upload. Через 15–30 минут сборка появится в App Store Connect → TestFlight.
7. **Проверьте на своём iPhone через TestFlight — обязательно.** iOS-версию ещё ни разу не запускали на настоящем устройстве. Добавьте себя во внутренние тестировщики, установите TestFlight и пройдитесь по основным экранам: клавиатура, вырезы экрана, экспорт и «Поделиться», диктовка, уведомления. Всё, что сломано, присылайте мне.
8. **Страница и подача.** Всё из [app-store.md](app-store.md): описание, скриншоты iPhone 6,9" и iPad 13", конфиденциальность, возрастной рейтинг, демо-аккаунт, заметки для проверки → выбрать сборку → «Отправить на проверку». Проверка обычно занимает 1–3 дня.

## Что на iPhone в первой версии работает иначе

- **Будильник по кругу** не звонит: приходит обычное уведомление со звуком. Настоящий будильник можно сделать позже через AlarmKit (iOS 26).
- **Виджетов нет.** На iOS их пишут на Swift (WidgetKit), это отдельная задача.
- **Календарь телефона:** вместо автоматической записи — выгрузка задач файлом .ics.
- **Разблокировка** только кодом, без Face ID. «Прятать в недавних» нет.
- **Push с сервера** (Web Push) в iOS-приложении не работает. Напоминания идут локальными уведомлениями, их планирует само приложение.

## Перед выходом в Google Play стоит доделать

- Кнопку «Пожаловаться на ответ» рядом с ответами ИИ. Правила Play о генеративном ИИ требуют жалобы прямо в приложении; сейчас это делается только через Поддержку.

### Безопасность данных (Data safety)

Общие вопросы:
- Собирает ли приложение или передаёт данные? — **Да**
- Все данные шифруются при передаче? — **Да** (только HTTPS)
- Можно ли запросить удаление данных? — **Да** (в приложении и по ссылке)
- Независимая проверка безопасности (MASA) — нет

Типы данных («собираются», т. е. уходят с устройства):

| Тип | Собирается | Передаётся третьим лицам | Обязательно? | Зачем |
|---|---|---|---|---|
| Личная информация → Адрес эл. почты | да | нет | **обязательно** (вход обязателен) | Функции приложения, управление аккаунтом |
| Личная информация → Имя | да | нет | необязательно (поле можно оставить пустым) | Управление аккаунтом |
| Финансовая информация → Другая финансовая информация | да (записи о тратах и бюджетах синхронизируются) | нет | необязательно (раздел «Финансы» можно не использовать) | Функции приложения |
| Сообщения → Другие сообщения в приложении | да (обращения в поддержку) | нет | необязательно | Поддержка пользователей |
| Фото и видео → Фото | да (картинки, которые пользователь добавил в карты и заметки; скриншот к обращению) | нет | необязательно | Функции приложения |
| Файлы и документы | да (карты и заметки синхронизируются) | нет | **обязательно** | Функции приложения |
| Действия в приложении → Другой пользовательский контент | да (задачи, дневник, привычки синхронизируются) | **да** — запросы к ИИ (Google Gemini, Groq, Anthropic), только с согласия | **обязательно** (передача ИИ — по желанию) | Функции приложения |
| Сведения о приложении и производительности → Журналы сбоев, Диагностика | да (анонимные отчёты об ошибках) | нет | необязательно (отключаются в Настройках) | Аналитика (устранение ошибок) |

**Не собираются:** местоположение, контакты, календарь (события читаются и пишутся только на устройстве), аудио (речь распознаёт системная служба), идентификаторы устройства и рекламы, история браузера.

Почему ИИ отмечен как «передача»: бесплатные модели Gemini/Groq могут использовать запросы для улучшения моделей, поэтому честнее отметить. Пользователь даёт согласие в приложении перед первым запросом.

### Декларации разрешений (Политика → Контент приложения / при загрузке сборки)

**Сервис переднего плана (Foreground service).** Типы `systemExempted` и `mediaPlayback`:
> Напоминание-будильник: пользователь включает «Как будильник» у задачи. В назначенное время сервис переднего плана проигрывает звук будильника по кругу и показывает уведомление с кнопками «Готово» / «Отложить», пока пользователь не выключит сигнал. Сервис работает только во время звонка (до 10 минут) и запускается только по точному будильнику, который поставил пользователь.

Нужно видео (до 30 с, ссылка на YouTube без доступа по ссылке): у задачи включить «Как будильник» на ближайшую минуту → заблокировать телефон → будильник звонит → «Готово».

**Полноэкранные уведомления (USE_FULL_SCREEN_INTENT).** Сценарий: «Будильник/таймер, который устанавливает пользователь».
> Напоминание-будильник, которое пользователь сам включил у задачи, показывается поверх экрана блокировки, как обычный будильник.

Если Google не одобрит — приложение всё равно работает: будильник звонит, а вместо полноэкранного окна появляется уведомление.

**Точные будильники.** `USE_EXACT_ALARM` убран. `SCHEDULE_EXACT_ALARM` декларации не требует: пользователь сам включает «Будильники и напоминания» (приложение спросит при включении «Как будильник»).

**Календарь (READ/WRITE_CALENDAR).** Отдельной декларации нет; используется только если пользователь включил «Записывать задачи в календарь».

**ИИ-контент.** Правила Play для генеративного ИИ требуют, чтобы на неприемлемый ответ ИИ можно было пожаловаться прямо в приложении. Это сделано: рядом с каждым ответом ИИ есть кнопка «Пожаловаться» — в чате ассистента, ИИ-плане на день, ИИ-помощнике карты и «Чате с картой», окне «Создать карту с ИИ», ИИ-разборе финансов, «Спросить у мозга», конспекте темы и вопросе дня. Она открывает Поддержку (вид «Проблема») с текстом ответа и пометкой «Жалоба на ответ ИИ»; жалоба приходит во «Входящие поддержки» и на почту. Для всего остального ИИ-контента (сгенерированные подзадачи, карточки, этапы целей) есть общий пункт Настройки → Поддержка → «Пожаловаться на ответ ИИ».

# 1.55 — «Что нового» для магазинов

App Store: поле «Что нового в этой версии» (ru и en-US). Google Play: «Примечания к выпуску» (`<ru-RU>`, `<en-US>`, `<kk>`).
В App Store не упоминать Android (правило 2.3.10); в Google Play — не упоминать iPhone.

## App Store — ru (≤4000)
```
• Поделиться картой по ссылке: «Только просмотр» или «Может редактировать». Ссылку можно отключить в любой момент
• «Доступные мне»: карты, которыми с вами поделились, видны в «Картах» с именем владельца, правки видны обоим через несколько секунд
• Голос сам заканчивает фразу — кнопки «Готово» во время записи больше нет
• После голосовой команды окно пишет «Сохранено»; отменить — крестиком рядом с записью
• Исправления голосового ввода
```

## App Store — en-US
```
• Share a map by link: “View only” or “Can edit”. You can turn a link off at any time
• “Shared with me”: maps shared with you appear in Maps with the owner’s name, and edits show up for both within seconds
• Voice ends the phrase by itself — no more Done button while recording
• After a voice command the window says “Saved”; undo with the cross next to the item
• Voice input fixes
```

## Google Play — ru-RU (≤500)
```
<ru-RU>
• Поделиться картой по ссылке: просмотр или правка
• «Доступные мне»: чужие карты с именем владельца
• Голос сам заканчивает фразу, быстрее и без кнопки «Готово»
• «Сохранено» после голосовой команды, отмена — крестиком
• Исправлено: ошибка «speechRecognition» при голосовом вводе
</ru-RU>
```

## Google Play — en-US (≤500)
```

• “Shared with me”: others’ maps with the owner’s name
• Voice ends the phrase by itself, faster and without a Done button

</en-US>
```

## Google Play — kk (≤500)
```
<kk>
• Картамен сілтеме арқылы бөлісу: қарау немесе өңдеу
• «Маған қолжетімді»: иесінің атымен басқалардың карталары
• Дауыс сөз тіркесін өзі аяқтайды, жылдамырақ және «Дайын» батырмасыз
• Дауыстық командадан кейін «Сақталды», болдырмау — ✕ арқылы
• Түзетілді: дауыстық енгізудегі «speechRecognition» қатесі
</kk>
```

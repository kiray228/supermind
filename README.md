# SuperMind — интеллект-карты, задачи и ежедневник

Бесплатная альтернатива Xmind: все функции открыты, без подписок. Работает в браузере, на телефоне (как приложение с экрана «Домой») и как APK на Android. Данные хранятся локально на устройстве и доступны без интернета.

## Возможности

**Интеллект-карты**
- 8 структур: интеллект-карта, логическая схема (вправо/влево), орг-структура, дерево, таймлайн, «рыбья кость», скобки
- 9 тем оформления, радужные ветви, 5 стилей линий, 8 форм тем, свои цвета, шрифты, толщина рамок и линий
- Подтемы, плавающие темы, связи между темами (с подписями), границы, итоги
- Маркеры (приоритеты, прогресс, флажки, звёзды, эмоции, символы), метки, заметки, ссылки, картинки
- Задачи в темах: статус, приоритет, даты начала и срока, исполнитель, прогресс
- Несколько листов в одном документе
- Режимы просмотра: **Карта**, **Структура** (outliner), **Гант** (диаграмма с перетаскиванием сроков)
- Презентация (Pitch), режим Zen, поиск, свернуть/развернуть ветви
- Перетаскивание тем, копирование/вставка, отмена/повтор, горячие клавиши как в Xmind
- Жесты на телефоне: щипок — масштаб, долгое нажатие — меню, двойной тап — редактирование
- Защита карты паролем (шифрование AES-256)

**ИИ (Claude)** — генерация карты по идее, «текст → карта», мозговой штурм, разбивка на задачи, объяснение темы, улучшение формулировок, перевод карты, резюме, чат с картой. Нужен свой API-ключ Anthropic (Настройки → ИИ); ключ хранится только на устройстве.

**Импорт:** Xmind (.xmind, включая старый XMind 8), Markdown, OPML, текст, файлы SuperMind (.supermind, а также старые .2mind).
**Экспорт:** PNG, PDF, SVG, Xmind, Word, Excel, PowerPoint, Markdown, OPML, резервная копия.

**Доска задач** — канбан с колонками, карточками, чек-листами, метками, сроками; задачи из всех карт попадают на доску автоматически.

**Ежедневник** — задачи дня со временем, задачи из карт по срокам, настроение, трекер привычек со стриками, дневник.

## Как пользоваться

- **Веб-версия:** откройте ссылку на сайт в любом браузере.
- **iPhone:** откройте сайт в Safari → «Поделиться» → «На экран „Домой“».
- **Android:** установите `SuperMind.apk` (разрешите установку из неизвестных источников) или в Chrome: меню ⋮ → «Установить приложение».

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка веб-версии в dist/
```

Сборка APK (нужны JDK 21 и Android SDK):

```bash
npm run build
npx cap sync android
cd android && gradlew.bat assembleRelease
```

APK появится в `android/app/build/outputs/apk/release/`. Ключ подписи — `android/2mind-release.jks`, пароли — `android/keystore.properties` (не публикуйте их и сохраните копию: без ключа нельзя выпустить обновление поверх установленного приложения).

Стек: React 19, TypeScript, Vite, Zustand, IndexedDB, Capacitor 8, Anthropic SDK.
